# Status Dashboard



The Status tab is the default landing page when you connect to your WiCAN Pro. It provides a real-time snapshot of the device's current health, network connections, and vehicle data.



To manually refresh the data on this page at any time, click the **Check status** button at the very bottom.



### Network Information

This section details how your device is currently communicating with the outside world.



* **WiFi Mode:** Shows the active wireless state (e.g., AP, Station, AP+Station, BLE+Station, or SmartConnect).

* **AP Channel:** The Wi-Fi channel (1-14) being used if the WiCAN is broadcasting its own Access Point.

* **WiFi Station:** Displays whether the device has successfully connected to your home router or hotspot (Connected / Not Connected).

* **Station IP:** The local IP address assigned to the WiCAN by your router (useful for accessing this web interface over your home network).

* **DNS Main / Backup:** The Domain Name System servers the device is using to resolve web addresses. 

* **Time Synced:** Shows "Yes" if the device has successfully pulled the current time from an NTP server. *Note: Time sync is required for secure HTTPS/TLS connections and Scheduled Wakeups.*

* **mDNS:** The local multicast hostname (usually `wican.local`) that can be used to access the UI without knowing the exact IP address.

* **VPN Status:** Shows if the built-in WireGuard VPN client is Connected, Connecting, or Disconnected.



### CAN & Protocol Settings

This section displays how the device is interacting with the vehicle's internal network.



* **CAN Bitrate:** The communication speed of the vehicle's CAN bus (e.g., 500K for most modern vehicles).

* **CAN Mode:** Shows "Normal" (capable of sending requests to the ECU) or "Silent" (listen-only mode, completely invisible to the car).

* **Port Type & TCP/UDP Port:** The active network protocol and port number used by third-party smartphone apps (like Car Scanner or RealDash) to connect to the WiCAN over Wi-Fi.

* **OBD Chip Status:** Displays the internal status of the ELM327 emulator chip.



### Power & System Health

Critical metrics for ensuring the device is operating safely without draining your car battery.



* **Battery Voltage:** A live reading of your vehicle's 12V system. If the engine is running, this usually reads around 13.5V - 14.4V. If the car is off, it sits around 12.2V - 12.6V.

* **Time to Sleep:** A live countdown timer showing exactly when the device will power down. If sleep is disabled, this will display N/A.

* **Uptime:** How long the device has been continuously powered on and running since its last reboot.



### Restart Diagnostics

The WiCAN Pro tracks its own reboot history. This is incredibly useful for debugging power issues or verifying that your sleep/wake triggers are working correctly.



* **Last Reset:** The hardware-level reason for the last reboot (e.g., Power On Reset, Software Reset, Watchdog Timer).

* **Planned Restart:** Shows if the device was intentionally rebooted by a specific system task (e.g., Firmware Update, User UI Reboot, Configuration Save).

* **Restart Source:** Tells you *why* the device woke up. This will show if it was woken by CAN bus activity, a scheduled timer, or a voltage change.

* **Last Boot Time:** The exact date and timestamp of the last boot (requires Time Synced to be "Yes").

* **Boot Count:** The total number of times the device has booted since the tracker was last cleared.

* **Unexpected Resets:** A counter of crashes or forced reboots. If this number is climbing, it may indicate a firmware bug or unstable power from the OBD2 port.
